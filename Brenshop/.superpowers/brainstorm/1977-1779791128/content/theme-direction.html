Principaux changements

Ce qui change

  • Couleurs : Les --pos-* hardcoded sont remplaces par les variables du theme (--accent, --card-bg, --body-bg, --text, --border, etc.)
  • Bordures : 3px solide noir → 1px solide var(--border)
  • Coins : 0px (carre) → 8-12px (arrondi)
  • Ombres : 3px 3px 0 (duree) → 0 2px 8px rgba (douce)
  • Animations : translate(-2px,-2px) → translateY(-2px) (hover subtil)
  • Typographie : 700-900 bold → 500-800 (plus lisible)
  • Fonds : #fef7ed/#fef3c7 → var(--body-bg)/var(--card-bg)

Ce qui reste

  • Layout grille (380px panier + catalogue flexible)
  • Toutes les fonctionnalites (recherche, categories, panier, paiement)
  • Barre de session caisse en haut du panier
  • Mini dashboard (Ventes, Revenu, Panier Moy, Articles)
  • Vues liste et grille des produits
  • Animations flash/bounce pour le panier
